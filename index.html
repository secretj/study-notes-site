공부 기록

비공개 저장소의 글을 읽고 고치려면 GitHub 토큰이 필요해요. 토큰은 이 브라우저에만 저장돼요.

토큰 만드는 법
  1. Fine-grained token 만들기를 열어요.
  2. Repository access 에서 Only select repositories 를 고르고 글 저장소 하나만 넣어요.
  3. Permissions → Repository permissions → Contents: Read and write 만 줘요.
  4. 만든 토큰(github_pat_ 로 시작)을 위에 붙여 넣어요.
